Here are the command needed to build and run fronted page locally.

Install Dependencies:

You need to install [npm](https://docs.npmjs.com/cli/v11/configuring-npm/install) and [Nodejs](https://nodejs.org/en/download)

cd frontend/Observtory\ Data\ Pipeline/

npm install

Spin up Webpage:

npm run dev

The page that to edit with the HTML that you are seeing on local host is located in frontend/Observtory Data Pipeline/src/App.jsx
