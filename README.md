# Observatory Frontend

Here are the commands needed to build and run the frontend page locally from scratch.

## Prerequisites

Make sure you have the following installed on your system:
* [Node.js](https://nodejs.org/en/download) (LTS version recommended, which includes `npm`)

## Getting Started

1. **Copy and paste these steps:**
   ```bash
   git clone https://github.com/Jqkeyyy/Observatory-Data-Pipeline.git
   cd Observatory-Data-Pipeline
   cd frontend/Observtory_Data_Pipeline
   npm install
   npm run dev
